2.3 Physics-Informed Neural Network (PINN)

A physics-informed neural network (Raissi et al., 2019) is used to bridge the gap between sensor data and the physical model. The Physics Informed Neural Network (PINN) is trained to predict the same state variables as the hydro-mechanical model (suction, water content, and factor of safety), but with a computationally faster approach. Key features of the PINN are:

• Architecture: The neural network is designed to handle both time-series data (rainfall) and spatially distributed data (suction and water content). It is a feed-forward neural network with multiple hidden layers and adaptive activation functions.

• Loss Function: The PINN is trained by minimizing a loss function that includes both data-driven terms (fitting the sensor data) and physics-based terms (ensuring the solution satisfies the governing partial differential equations).

• Data Integration: The PINN is continuously updated with new sensor data, refining its predictions by learning from real-world measurements while adhering to the physical laws governing the system.

The full system operates in a data-assimilation cycle: (I) Ingestion: new rainfall and sensor data are continuously integrated into the system; (II) Prediction: the PINN provides updated predictions of suction, water content, and factor of safety; (III) Alert Generation: If the predicted factor of safety drops below a pre-defined threshold, the system triggers an alert.
