**Full Content:**

To solve these problems, we propose to combine the best of both worlds in a single model that offers regional scale predictions, mean- ingful geotechnical results, and a near-real-time predisposition once pre-trained.

To do so, we estimate geotechnical parameters 𝑮(𝑠) given environ- mental variables 𝑿(𝑠) with some sort of highly non-linear functional approximation using deep learning function F. Then, we use those parameters through a physics-based landslide estimation technique to produce landslide susceptibility values. Therefore the approximated geotechnical parameters can be defined as 𝑮(𝑠) = F(𝑿(𝑠)) ∣ 𝑿(𝑠) = 𝒙(𝑠).

In this study, we opted to define a simple architecture where the neural network function F is an ANN with 16 neural network blocks. Each block consists of a dense neural network of 64 neurons, except for the last block, a batch normalization layer (Ioffe and Szegedy, 2015), a dropout layer with a dropout ratio of 0.3 (Srivastava et al., 2014), and a rectified linear unit (ReLU) activation function (Yarotsky, 2017; Nair and Hinton, 2010). The neural network itself contains the train- able weights and biases, which are initialized using random normal initialization (Thimm and Fiesler, 1995). The batch normalization and dropout layers prevent the model from overfitting by regularizing the distribution of each batch and randomly deactivating 30% of neurons. The ReLU activation changes the data flow to convert the model into a non-linear one. The last block of the neural network consists of a variable number of neurons, which are equal to the number of geotechnical parameters that we wish to estimate, which in this case is two. To estimate the geotechnical parameters, the input dataset to this model is all the environmental factors that influence the landslide slope stability (𝑿(𝑠) = 𝒙(𝑠)); once such variables are passed through the neural network model, each of those layers gets processed through each layer and provides the 𝑮(𝑠) as an intermediate output of the neural network part, which is then passed into the physics-based part of the model.

Notably, which types and how many geotechnical parameters 𝑮(𝑠) we use depends on our assumptions and the underlying physical mech- anism we want to solve. Once 𝑮(𝑠) is estimated with the function F, it is then passed, together with required environmental conditions such as terrain slope, through a ‘‘Landslide-Physics’’ layer in the model, which respects the physics of the failure mechanism.
